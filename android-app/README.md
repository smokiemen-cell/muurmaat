# Muurmaat AR

Native Android ARCore prototype for measuring a wall.

1. Open this folder in Android Studio.
2. Let Gradle sync and install the missing dependencies.
3. Connect an ARCore-supported Android phone with USB debugging enabled.
4. Run the `app` configuration.
5. Choose `Lengte` or `Hoogte`, tap a start point on the wall, walk along the wall, and tap the end point.

The phone must support Google ARCore and have Google Play Services for AR installed.
